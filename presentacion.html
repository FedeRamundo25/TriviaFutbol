⚽ Trivia Fútbol — Full-Stack Web Application

Plataforma web de gamificación deportiva basada en una arquitectura desacoplada RESTful API.

🎮 3 Game Modes Equipos, Jugadores y Contra el Reloj con penalización dinámica.
🔒 Security & Auth JWT, hashing `bcrypt` (12 rounds) y Rate Limiting por endpoint.
⚡ High Capacity DB +140 equipos y +1.900 jugadores indexados en PostgreSQL.
🤖 Automated CI/CD Pipeline en GitHub Actions con suite de tests automatizada.

🏛️ Architecture & Infrastructure

Capa Tecnología Hosting / Servidor Descripción
Frontend HTML5, CSS3, Vanilla JS Render Static Site Interfaz fluida, responsive y modular, sin frameworks pesados.
Backend API Node.js 20, Express 5 Render Web Service API RESTful estructurada en capas (Controllers, Services, Repositories).
Database PostgreSQL 15 Neon Serverless Esquema relacional optimizado con migraciones y datos normalizados.
Ops / Crons Health Check Jobs Cron-Job.org Pings automatizados a /api/health para evitar cold-starts.

⚙️ Tech Stack Breakdown

  [ Frontend: HTML / CSS / JS ]
               │
               ▼  (HTTP / JWT Auth)
  [ Backend API: Express 5 + Joi ]
        ├── Auth Service (bcrypt / JWT)

📊 Main API Endpoints

  • POST /api/auth/register | POST /api/auth/login | GET /api/auth/me
  • POST /api/game/start | POST /api/game/:sessionId/answer | POST /api/game/:sessionId/finish
  • GET /api/ranking/:mode — Cálculo de Top 25 partidas globales.
  • GET /api/health — Endpoint de monitoreo para salud del servicio.

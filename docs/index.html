01 / THE GAME

Football facts
meet friendly
competition.

Trivia Fútbol is a web quiz built around the clubs and players fans love. Sign in, choose a challenge, and build your score one answer at a time.

Made as a full-stack project, it connects a lightweight web interface to a dedicated API and stores game sessions and rankings in PostgreSQL.

05 / QUALITY & DELIVERY

Built to be tested.
Automated to ship.

Practices and safeguards visible in the codebase and its workflows.

01 / INPUTS & SECURITY

Guardrails in the API

Joi schemas validate account and game requests. Passwords use bcrypt hashing; Helmet and route rate limits add server-side protections.

02 / BACKEND DESIGN

Clear responsibilities

Routes, controllers, services, and repositories separate the API concerns. PostgreSQL schema changes are managed with migrations.

03 / TESTING

Tests around key flows

Jest and Supertest cover unit and database integration cases; Playwright exercises registration, a full teams round, and the results screen in Chromium.

06 / RUN IT LOCALLY

These commands start the API and prepare the local database. Add your local values to the environment file when prompted.

Read the full setup guide ↗
● ● ● LOCAL SETUP 01—05
# Start PostgreSQL
docker-compose up -d

# Configure and start the API
cd backend
cp .env.example .env
npm install
npm run migrate
npm run seed
npm run dev

Open frontend/pages/login.html with Live Server. For local play, set the API address in frontend/pages/js/api.js to http://localhost:3000/api.
